1. FFmpeg and PyAV (the `av` package)  -  read this one
--------------------------------------------------------
Hevanti reads audio and video files (recordings) with the Python package `av` (PyAV,
BSD-3-Clause, https://github.com/PyAV-Org/PyAV). The package comes with FFmpeg libraries
as separate DLL files, in `python\Lib\site-packages\av.libs`. The FFmpeg build used by the
PyAV wheels includes GPL components (for example libx264 and libx265), so these libraries
are provided under the GNU General Public License, version 2 or later, and the rest of
FFmpeg under the GNU Lesser General Public License, version 2.1 or later.
Hevanti does not change these libraries and uses them only to decode files; they are
separate files, and you may replace them with another build of the same libraries.

  Texts:  licenses\GPL-2.0.txt  and  licenses\LGPL-2.1.txt
  Source code of the libraries (the exact versions are the ones inside the installed
  `av` package, see `python -m pip show av`):
    FFmpeg      https://ffmpeg.org/download.html
    x264        https://www.videolan.org/developers/x264.html
    x265        https://www.x265.org/
    PyAV        https://github.com/PyAV-Org/PyAV
    the builds  https://github.com/PyAV-Org/pyav-ffmpeg
  Written offer: whoever received Hevanti may ask for the complete source code of these
  GPL/LGPL libraries, as they are in this package, by writing to hevanti.support@gmail.com.
  We will send it, or the link to it, for at least three years from the date of the
  release you received.
